# ResNet18 梯度与显存测量

FP32、register、120×160，训练模式 BN 和 Adam。每次预热 5 步，再测 20 步。每个配置交替启动旧、新代码各 3 次。每个进程的步时取中位数，下表列进程间中位数与样本标准差。CuPy 池列为单次进程申请峰值的中位数。

| 配置 | 旧步时 ms | 新步时 ms | 旧池 MiB | 新池 MiB | 旧 / 新触及功耗墙 |
| --- | ---: | ---: | ---: | ---: | --- |
| cifar-w64-b2 | 44.83 ± 0.42 | 50.97 ± 0.16 | 1329.7 | 704.6 | 0% / 18% |
| cifar-w16-b16 | 68.35 ± 3.55 | 84.58 ± 0.50 | 2344.9 | 1241.0 | 43% / 50% |
| imagenet-w16-b128 | 48.20 ± 0.20 | 57.79 ± 0.20 | 2211.8 | 1076.8 | 0% / 13% |

另用 cifar stem、w16 逐步增大 batch，在首次出现非本地显存后按整数二分。容量试验先上传固定设备批次并同步，再记录 WDDM 的进程 Local Usage 和 Non Local Usage。容许相对该基准增加 1 MiB 的计数波动。
- before 的最大驻留 batch 为 46，相邻的 47 已超出。
- after 的最大驻留 batch 为 93，相邻的 94 已超出。

原始测量与协议保存在本目录的 JSON 文件中。

三个配置的池峰值下降约 47%–51%，中位步时增加约 14%–24%。默认继续保存列缓冲，需要扩大 batch 时可设置 `MYFLOWS_RECOMPUTE_IM2COL=1`。卷积层也接受 `recompute_im2col=True`。6 个批次、4 个后端的全部 1,968 个参数梯度和 24 个 loss 与缓存版本逐字节一致。原始 FP64 参照与参数梯度保存在[数值报告](../recompute-numerics-001/report.md)同目录。包含重算的 S5 复测见[跨框架报告](../../frameworks/resnet18-recompute-001/report.md)。
