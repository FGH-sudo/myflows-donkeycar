## 单步梯度相对 FP64 的误差（ResNet18 w16，imagenet stem，128×3×120×160，训练模式 BN，seed 1）

相同 float32 参数与 batch。62 个参数统计相对误差 ‖g − g64‖₂/‖g64‖₂ 的中位数、90 分位与最大值；另 20 个是紧接训练模式 BN 的卷积 bias，真实梯度恰为 0（BN 减去了通道均值），“零梯度噪声”列给出其中最大的 ‖g‖₂，以其余参数 ‖g64‖₂ 的中位数为单位（纯舍入噪声）。最后两列是前向的对照：17 个 ReLU 输入各自的最大相对误差（max|x − x64| / max|x64|）的中位数，以及与同一代码 FP64 结果符号相反的 ReLU 输入个数。符号相反的元素上局部梯度在 0 与 dy 之间跳变，一个这样的元素就能让该 ReLU 之前（靠近输入一侧）各层的参数梯度出现 1e-3–1e-2 量级的偏差，这与累加误差无关。
