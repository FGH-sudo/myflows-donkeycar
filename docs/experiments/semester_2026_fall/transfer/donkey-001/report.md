## 按最佳验证轮的补充统计

学习率 1e-3、batch 2 时多数配置在第 3 轮验证误差回升，人工基线 scratch-cifar 末轮均值为 0.18510。上表的“最终验证 MAE”与到达时间都以末轮为准，到达目标因此偏宽。下表取每个种子 3 轮内的最佳验证角度 MAE，到达时间以同 seed 人工基线的最佳值为目标，3 轮内未到达记为“未达”。训练保存的 best checkpoint 按验证 loss（转向与油门的 MSE）选择，其角度 MAE 可能与逐轮最小值不同。本节只用验证集，不增加测试集评估。

按最佳轮次，pretrained-k4 的三种子均值 0.02327 低于人工基线的 0.03436，种子间标准差由 0.01525 降到 0.00108。与人工基线按种子配对的差值为 −0.01109，95% 区间 [−0.04983, +0.02764] 跨过零，因此不宣称超出噪声的改进。该节由 `benchmark.transfer_study.donkey_best_epoch_section` 从 formal/summary.json 生成。

按验证集锁定 pretrained-k4，闭环评估使用该配置 seed 3 的最佳验证 checkpoint。表中终值使用最后一轮 checkpoint。一次性测试清单包含部署候选的单独记录。

该部署 checkpoint 的独立测试 MAE 为 0.02478。人工基线 scratch-cifar 的三个种子分别在第 2 轮达到验证 MAE 0.03325、0.01971、0.05014，均值 0.03436。核对历史 formal-full-002 中 t001/attempt-2、t002/attempt-1、t003/attempt-1，全部九个逐轮验证 MAE 与本次记录数值相同。最后一轮 MAE 的均值为 0.18510，历史报告的 0.03436 采用每个种子的最佳验证轮次。

原始结果分别在 pilot/ 与 formal/，每个 attempt 保存命令、完整 config、metrics、resources、result 和 checkpoint。summary.json 保留每个种子的训练曲线、初始 MAE、到达基线的步数和内存口径。
复现命令为 `python -m benchmark.transfer_study donkey --tree <实验代码树> --out runs/stage3/donkey-repro`。
