# AutoPilot 诊断示例

## 迁移学习策略

线性探测只使用本次训练分区的 1,535 帧。在分离的时间块上取 96 帧拟合岭回归，另取 32 帧估计验证误差。目标域的转向 MAE 为 0.06410，训练标签中位数预测器为 0.17223。按相对误差下降计算的得分为 0.62782。课程的四种情况采用训练数 3,000 和得分 0.5 两处分界，本例落在小样本、相似度较高的一组，候选冻结 5 段，骨干学习率倍率 0.1。完整冻结时仅任务头更新。

本机证据见 `runs/stage3/transfer-probe-real/result.json` 的 transfer.probe。完整的规则输出保存在本目录 examples.json。
