## 课件数据记录表（NumPy 为基线）

按课件第 72–73 页的口径：随机种子固定，每个规模测 3 轮（每轮依次测完全部实现再开始下一轮），每轮取多次调用的平均，表中为 3 轮的中位数；下一节的中位耗时取全部调用的中位数。GPU 只计 kernel（CUDA event），传输时间单独见“传输”一节；加速比 = NumPy 时间 / 该实现时间。分块版的线程块负责 16×16 的输出子块，共享内存版用 16×16 的共享内存 tile。寄存器分块版是课件三版之外的优化：线程块负责 128×128 的输出块，每个线程在寄存器里算 8×8 个输出，float4 读取，共享内存双缓冲（fp32 每次取 16 层 k，即原生卷积默认的 GEMM 引擎）。四版都是 fp32 顺序累加，结果逐位相同。误差以 NumPy 的 float32 结果为基线：最大绝对误差为 max|C − C_NumPy|，相对误差为 ‖C − C_NumPy‖_F / ‖C_NumPy‖_F。
